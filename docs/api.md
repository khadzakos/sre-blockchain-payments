# HTTP API

JSON, HTTP/1.1, базовый префикс `/api`. Авторизация не требуется.
Это учебное окружение; Compose публикует API только на localhost.

## Маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/invoices?status=draft&limit=20&offset=0` | Список; limit 1–100, по умолчанию 50 |
| POST | `/api/invoices` | Создать черновик, ответ 201 |
| GET | `/api/invoices/{id}` | Карточка |
| PUT | `/api/invoices/{id}` | Полностью заменить условия черновика |
| DELETE | `/api/invoices/{id}?version=1` | Удалить черновик, ответ 204 |
| POST | `/api/invoices/{id}/issue` | Выставить |
| POST | `/api/invoices/{id}/cancel` | Отменить |
| GET | `/api/invoices/{id}/events` | История по версии |
| GET | `/healthz` | Жив ли HTTP-процесс |
| GET | `/readyz` | Доступна ли PostgreSQL |
| GET | `/metrics` | Prometheus metrics |

Тело создания:

```json
{
  "description": "Разработка сайта",
  "amount": "10000000",
  "chain_id": 84532,
  "token_address": "0x1111111111111111111111111111111111111111",
  "recipient_address": "0x2222222222222222222222222222222222222222",
  "expires_at": "2030-01-01T12:00:00Z"
}
```

Адреса здесь демонстрационные, не адреса реального USDC или кошелька.
API проверяет формат EVM-адресов, но пока не проверяет существование контрактов.
Сумма — положительное целое до `2^256-1`, передаётся строкой.

Для PUT добавьте `"version": 1` к полным условиям.
Для issue/cancel тело содержит только текущую версию: `{"version":1}`.
Неизвестные JSON-поля отклоняются. Максимальный размер тела — 8 КиБ.

Ответ ошибки: `{"error":"описание"}`. Коды: 400 — невалидные данные,
404 — счёт не найден, 409 — недопустимое состояние
или устаревшая версия, 500 — внутренняя ошибка.

После выставления условия неизменны. Истечение срока асинхронно, задержка
до следующего прохода worker; отмена после срока запрещена даже до его прохода.
Операция выставления не идемпотентна по старой версии: повтор вернёт 409.
Повтор POST создания создаёт новый счёт; idempotency key — будущая доработка.

Ответы содержат `X-Request-ID` и `X-Trace-ID`. Принимается W3C `traceparent`.
Параметры URL, тела, ключи авторизации и SQL-аргументы не записываются в логи.
